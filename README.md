# High-Frequency Orsntien-Uhlenbeck Spread Modeling

This repository contains a data analysis pipeline that I built to collect and clean high-frequency (100ms) trading data from CCXT. The resulting data is then used to find Ornstien-Uhlenbeck parameters for spread modelling.

## File Breakdown
data_*.py implement three different methods of collecting price data using CCXT trade history. This goal is to get sub-second frequency data.

clean_1.py implements cleaning and preparation methods. Preparation of data involves combining separate time series data of a trading pair on two different exchanges into a single DataFrame modelling spread. To deal with missing values for a particular timestamp, we have three approaches. We can continue with the irregular data, or we can make it regular through linear interpolation, or linear interpolation with added noise to maintain data patterns.

OU_params.py uses the resulting data from clean_1.py to calculate Ornstien-Uhlenbeck process parameters. It implements two approaches, regression and MLE. MLE is designed to be compatible with irregular data. MLE is set up as a class that utilizes NLOPTS library to find the Maximum likelihood estimate. The optimization method is with the Sbplx algorithm as suggested in https://arxiv.org/pdf/1811.09312.

OU_process.py implements simulation of OU process using parameters generated by methods on OU_params.py
